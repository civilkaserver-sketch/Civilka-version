# Civilization Client 1.21.8 (Fabric)

Готовая сборка клиента для сервера **Civilization**.

В сборку включены:
- **Ядро**: Fabric Loader 0.19.5 (Minecraft 1.21.8) + полный комплект библиотек
- **Моды**: 18 модов (PlayerTrading Fabric с рынком игроков и кастомными ивентами/NPC, Sodium, Iris Shaders, ImmediatelyFast, Lithium, FerriteCore, C2ME, Xaero's WorldMap & Minimap, FallingTree, ModMenu, Ok Zoomer и др.)
- **Ресурспаки**: Полный серверный пак `CivilizationServerPack.zip` со всеми кастомными текстурами и моделями
- **Шейдеры**: Встроенная поддержка Iris Shaders для максимального FPS и красивой графики
- **Готовые настройки**: Оптимизация Sodium, настроенная миникарта, сервер уже добавлен в список сетевой игры.

## Быстрая установка (1 клик)

### Вариант 1 (Через Git):
```bash
git clone https://github.com/civilkaserver-sketch/Civilka-version.git
cd Civilka-version
install.bat
```

### Вариант 2 (Без Git):
1. Нажмите зеленую кнопку **Code** -> **Download ZIP** на странице репозитория.
2. Распакуйте архив в любую папку.
3. Запустите **`install.bat`** (или **`Установка_Civilization.bat`**).
4. Запустите Minecraft Launcher / TLauncher и выберите версию **`Civilization`** (Fabric 1.21.8).
