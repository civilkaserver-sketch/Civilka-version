# Civilization Client 1.21.8

Готовая сборка клиента для сервера **Civilization**.

В сборку включены:
- **Ядро**: Forge 1.21.8 (58.1.7) + полные библиотеки
- **Моды**: 13 модов (Playertrading с рынком игроков и кастомными артефактами, OptiFine HD, Xaero's WorldMap & Minimap, 3D Skin Layers, FallingTree и др.)
- **Ресурспаки**: Все необходимые паки, включая `Angel Elytra Wings` со всеми кастомными текстурами артефактов (Кровавый топор, Звездный оберег, Поступь тени, Крылья ангела)
- **Шейдеры**: MakeUp UltraFast, Complementary Unbound, Bliss, Photon и др.
- **Готовые настройки**: Оптимизация OptiFine, включенные текстуры CIT, готовый сервер в списке сетевой игры.

## Быстрая установка (1 клик)

### Вариант 1 (Через Git):
```bash
git clone https://github.com/civilkaserver-sketch/Civilka-version.git
cd Civilka-version
install.bat
```

### Вариант 2 (Без Git):
1. Нажмите зеленую кнопку **Code** -> **Download ZIP** на странице репозитория.
2. Распакуйте архив в любую папку.
3. Запустите **`install.bat`** (или **`Установка_Civilization.bat`**).
4. Запустите Minecraft Launcher / TLauncher и выберите версию **`Civilization 1.21.8`**.
